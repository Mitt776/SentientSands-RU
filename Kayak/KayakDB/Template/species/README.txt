Species overlays are grouped by persona category and then by exact race folder.

Layout:
- species/animals/<RaceName>/Chat/
- species/animals/<RaceName>/Biography/
- species/animals/<RaceName>/RadiantSpeaker/
- species/ferals/<RaceName>/Chat/
- species/ferals/<RaceName>/Biography/
- species/ferals/<RaceName>/RadiantSpeaker/
- species/machines/<RaceName>/Chat/
- species/machines/<RaceName>/Biography/
- species/machines/<RaceName>/RadiantSpeaker/
- species/sapients/<RaceName>/Chat/
- species/sapients/<RaceName>/Biography/
- species/sapients/<RaceName>/RadiantSpeaker/

Race folder names should use underscores instead of spaces, for example:
- Beak Thing -> Beak_Thing
- Iron Hound -> Iron_Hound
- Bull -> Bull

Prompt files inside those folders must use a numeric prefix such as `1_rules.txt` or `2_style.txt`.
